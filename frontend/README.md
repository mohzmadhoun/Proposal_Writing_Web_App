# Frontend (React + TypeScript)

The frontend provides the admin shell for:
- knowledge base management flows
- proposal intake and generation workflow
- proposal history and configuration sections

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```

## Current implementation

- Login/register authentication
- Workspace management
- Knowledge entities CRUD starter flows
- Job intake and proposal generation
- Proposal history preview
- App sections editor
- Markdown import trigger
